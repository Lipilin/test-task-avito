## Описание

Проект представляет собой монорепозиторий с двумя частями: `server` и `client`. В рамках задания я разработал клиентскую часть. Также внёс два изменения в серверную часть:

- Исправил название пакета server на `@avito/server` для импорта типов данных из `client`
- Исправил обработку CORS: в исходной версии сервер не обрабатывал `OPTIONS`-запросы, из-за чего блокировались `DELETE`-запросы (отмена бронирования). Добавил корректную обработку `OPTIONS`, другого способа решить проблему не нашёл.

Остальная серверная логика осталась без изменений.

Клиентская часть — это SPA на React с TypeScript, взаимодействующее с сервером через WebSocket и HTTP.

## Технологии

- **React 19** — библиотека для построения пользовательских интерфейсов.
- **TypeScript** — строгая типизация.
- **Vite** — сборка и разработка.
- **React Router DOM** — маршрутизация (BrowserRouter).
- **React Datepicker** — готовый компонент календаря.
- **React Input Mask / React IMask** — маски для полей ввода.
- **Zod** — валидация данных форм.
- **ESLint** — линтинг и форматирование кода.
- **Vitest** — тестирование.

## Особенности реализации

- Для работы с WebSocket используется кастомный **WebSocketProvider** и **WebSocketContext** (собственная реализация)
- Выпадающие списки (dropdown), формы и другие UI-элементы написаны вручную, без готовых библиотек компонентов.

## Инструкция по запуску

1. Клонируйте репозиторий.
2. Выполните `npm install` из корня проекта.
3. Выполните `npm run dev` из корня проекта.

Команда `npm run dev` запускает одновременно клиент и сервер с помощью `concurrently`. Сервер уже содержит все необходимые изменения, дополнительных настроек не требуется.

После запуска клиент будет доступен по адресу, указанному в терминале (обычно `http://localhost:5173`).

## Структура проекта

- `client/` — исходный код React-приложения.
- `server/` — серверная часть (модифицирована для CORS и импорта типов, остальное без изменений).

## Тестирование

Тесты реализованы только для клиентской части. Для их запуска перейдите в папку `client` и выполните одну из команд:

- `npm run test` — однократный запуск всех тестов.

## Структура проекта
- `assets/` — статические файлы (изображения, шрифты и т.п.)
- `components/` — переиспользуемые компоненты приложения
- `layout/` — крупные UI-блоки (карточки комнат, карточки бронирований, шапка и т.д.)
- `pages/` — страницы приложения (список комнат, бронирования, бронирования пользователей)
- `ui/` — мелкие UI-элементы (инпуты, календарь, кнопки и т.п.)
- `test/` — настройка тестового окружения и моки для API
- `utils/` — вспомогательные функции
  - `api/` — интерфейс для взаимодействия с REST API
  - `context/` — React-контексты
  - `hooks/` — кастомные хуки (например, `useDebounce`)
  - `providers/` — кастомные провайдеры (`WebSocketProvider` и др.)
  - `validation/` — схемы валидации (Zod)
  - `other/` — прочие утилиты (работа с датами, форматирование данных для отображения)
